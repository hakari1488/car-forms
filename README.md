# Справочник форм автомобилей

Учебный проект по веб-программированию: сайт-справочник типов кузова автомобилей с административной панелью. Реализован на чистом HTML, CSS и JavaScript без сервера и базы данных.

## 🔗 Демо

**Публичная ссылка:** https://hakari1488.github.io/car-forms/

## Возможности

- Каталог форм кузова с поиском и фильтром по категории
- Постраничный вывод (6 карточек на страницу)
- Страница просмотра с галереей изображений и счётчиком просмотров
- Административная панель с авторизацией
- Добавление, редактирование и удаление записей
- Загрузка изображений (JPG, PNG, WEBP, до 500 КБ)
- Управление категориями
- Адаптивная вёрстка

## 🔐 Вход в админ-панель

- **Логин:** `admin`
- **Пароль:** `admin123`

## Технологии

- HTML5
- CSS3 (Grid, Flexbox, CSS-переменные)
- JavaScript (ES2017+, async/await)
- LocalStorage и SessionStorage как хранилище
- FileReader API для загрузки изображений
- Web Crypto API для хеширования пароля
